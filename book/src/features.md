# Features

## Core File Management

- Browse internal storage, SD card, and USB OTG
- Breadcrumb path bar with sort and filter
- Show hidden files
- Select (long-press, select all, invert, range)
- Copy, move, delete, rename, new file/folder
- Dual-pane mode
- Tabs and history per pane
- Bookmarks
- Task queue with progress and cancel
- Search by name
- Open with / share

## Archives

- ZIP browse, extract, create
- 7z, tar, gz/bz2/xz, zstd support
- RAR read-only
- Password-protected archives

## Editors and Viewers

- Text viewer/editor with syntax highlighting
- Hex editor
- Image viewer
- Media player
