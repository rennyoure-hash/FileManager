# Welcome to MT Explorer

MT Explorer is an advanced dual-pane Android file manager built with Jetpack Compose and Kotlin.

## Features

- Dual-pane browsing
- Fast multi-selection
- File operations (copy, move, delete, rename)
- Conflict handling
- Storage access (internal, SD card, USB)

## Installation

Download the latest APK from the [Releases](https://github.com/rennyoure-hash/FileManager/releases) page and install it on your Android device.
